# 履历式记忆

[English](README.md)

`@onenightcarnival/dsh-memory` 在左侧栏提供「记忆」入口。简历包含个人信息与能力、工作经历、项目经历；关联的经历档案记录背景、行动、观察结果、证据、经验与适用边界。

## 使用

- 「简历」以 A4 纸张宽度展示个人信息与能力、工作经历、项目经历；内容超过一页时纵向延展。窄屏适配可用宽度。
- 「目录」提供全局个人信息入口，工作经历、项目、档案分列浏览。选中任意工作、项目或档案，右侧显示并可编辑该条目自身内容；下一级列表独立展示。切换上级会清除下级选择。窄屏收起上游列，通过路径导航返回。未关联工作的项目显示在「独立项目」。旧版直接关联工作的档案保留在原位置。
- 同级条目按创建时间排序，默认最新在前，可切换最早在前。编辑内容不改变创建时间。
- 从工作经历新增项目、从项目新增档案时自动填写关联。首次安装为空白履历。
- 人工修改保护对应字段。编辑器中的复选框可逐字段允许 Agent 后续修改。
- 「允许 Agent 使用工具」控制 `memory_read`、`memory_commit` 及配套提示的注入，默认开启。开关持久化，不创建履历版本；关闭后已分派的工具调用也会被拒绝。
- 「版本历史」展示修改者、来源与字段差异。恢复版本会替换整份履历，生成新版本，并将恢复字段标记为人工确认。
- 导出当前简历和档案的结构化 JSON，不包含版本历史或工具开关。导入与版本恢复均保留当前工具开关。导入替换当前内容、生成新版本，并保护导入字段。
- 移除条目保留历史。移除父条目前须先移除或更改引用。「清空记忆」经确认后删除全部履历、档案和版本历史，无法恢复；工具开关不变。版本号继续递增，清空前的编辑草稿无法覆盖清空结果。

## 履历字段

工作经历包含公司（`organization`）、时间（`period`）、岗位（`jobTitle`）、主要事迹（`highlights`）。每条经历记录该时间段内的一个岗位，兼任角色写入主要事迹；岗位变化时拆分经历。时间为自由文本，不自动检查时间重叠。

## Agent 契约

| 工具 | 契约 |
|---|---|
| `memory_read` | 不传 `id` 时返回简历和版本；传入工作 ID 返回该条目及项目，传入项目 ID 返回该条目及档案。 |
| `memory_commit` | 提交 `baseRevision`、`summary` 和增量 `changes`；整批成功或失败。人工确认字段、已关闭的工具会阻止 Agent 修改。 |

提示引导 Agent 读取相关经历，并在验证过的阶段结果产生后更新。更新依赖 Agent 在当前任务内调用工具；本版不运行后台抽取、自动会话扫描或单独的抽取模型调用。证据引用会被保存，其真实性不会自动核实。记忆作为数据提供，不覆盖当前指令。不保存凭证或完整对话流水。

## 存储与配置

数据位于 `$DSH_HOME/memory/career.json`，默认 `~/.dsh/memory/career.json`。本地会话共享一份个人履历，项目作为明确的独立条目保留。文件包含当前状态、工具开关与历史快照。历史快照仅包含履历内容。写入使用独占 `.lock` 文件和原子替换。旧版本写入被拒绝；即使修改不同字段，旧版本也需要刷新。进程崩溃可能留下锁：停止全部记忆写入进程，确认锁已失效后，仅移除 `career.json.lock` 再重试。损坏数据不会被自动重置。

存储与导出格式为版本 3，支持读取和导入版本 1、2。旧工作经历的名称、角色、职责和成绩按原顺序合并至主要事迹；岗位留空，关联 ID 保持不变。合并字段中有人工保护项时，主要事迹保持保护。历史快照同步转换，读取不写盘，下次保存时持久化新格式。旧条目的创建时间取首次出现的历史快照时间；缺少历史依据时显示时间未知。无创建时间的导入条目使用已有同 ID 时间或导入时间。旧版开关变更产生的历史版本保留，新开关操作不再创建版本。

容量限制：1,000 个条目、每字段 12,000 字符（主要事迹 50,000 字符）、每次 100 项变更、HTTP／导入输入 2 MiB、历史存储 32 MiB。超限拒绝修改，不自动裁剪历史。API 仅接受回环请求，要求宿主浏览器会话认证。

独立插件 ID 为 `memory`，配置 `{ enabled: false }` 关闭宿主功能。toolkit 模块键为 `memory`，设为 `false` 同时关闭宿主与界面。独立安装和集成安装互斥。

## 开发

Node.js 22.19+ 或 24+，pnpm 11；dsh `0.2.0-rc.2`。

```sh
pnpm --filter @onenightcarnival/dsh-memory build
pnpm --filter @onenightcarnival/dsh-memory typecheck
pnpm --filter @onenightcarnival/dsh-memory test
```

`src/model.ts` 定义字段与关联；`src/store.ts` 负责校验、历史和并发；宿主 API 与工具共用存储。界面字典键集一致，跟随宿主语言。测试覆盖持久化、人工保护、旧版本写入、原子失败、无效数据与版本恢复。
